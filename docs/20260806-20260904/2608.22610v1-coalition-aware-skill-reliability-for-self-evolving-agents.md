## 摘要
智能体技能是从交互轨迹中提炼出的结构化产物，可从技能库中动态复用，已成为使基于大型语言模型（LLM）的自进化智能体能够从过往经验中学习的关键机制。然而，现有工作大多聚焦于技能的操作性层面，如获取、演化和检索，却留下了一个更根本的可靠性问题悬而未决：智能体技能库中积累的技能是否确实产生了积极的机制性贡献？我们通过在不同的技能库组成和部署领域中进行系统性技能库审计来探究这一问题，并度量由此引发的智能体行为变化。这些审计揭示了两种反复出现的可靠性失败：联盟污染，即技能库层面的收益掩盖了联盟层面的负面技能贡献；以及跨领域效用逆转，即源领域有益的技能在迁移后效果发生逆转。这些发现促使我们提出两种可靠性干预措施：技能积累过程中的联盟感知技能选择，以及迁移后的无标签技能遮蔽。联盟感知技能选择（CASS）利用采样的Shapley边际值为当前技能库挑选更可靠的候选技能。无监督技能遮蔽联盟优化器（u-SMCO）遮蔽那些在排除后能提升无标签目标领域数据检索质量的迁移技能。在LoCoMo、LongMemEval、HotpotQA和ALFWorld上进行的智能体实验表明，与强基线的基于技能的自进化智能体相比，CASS和u-SMCO始终能提升任务性能和跨领域泛化能力。除准确性外，联盟条件可靠性建模还降低了对强化学习过程中噪声结果奖励波动的敏感性，并揭示了基于隔离的技能评估的局限性。

## Abstract
Agent skills, structured artifacts distilled from interaction trajectories and dynamically reused from skill banks, have become a central mechanism for enabling large language model (LLM)-based self-evolving agents to learn from past experience. Yet existing work has largely focused on the operational aspects of skills, such as acquisition, evolution, and retrieval, while leaving a more fundamental reliability question unresolved: Do accumulated skills in an agent's skill bank actually make positive mechanistic contributions? We investigate this question through systematic skill-bank audits across alternative bank compositions and deployment domains, measuring the resulting changes in agent behavior. These audits reveal two recurring reliability failures: coalition pollution, where bank-level gains conceal negative coalition-level skill contributions, and cross-domain utility reversal, where source-beneficial skills reverse their effects after transfer. These findings motivate two reliability interventions: coalition-aware skill selection during skill accumulation and label-free skill masking after transfer. Coalition-Aware Skill Selection (CASS) selects more reliable candidate skills for the current bank using sampled Shapley marginals. Unsupervised Skill-Masked Coalition Optimizer (u-SMCO) masks transferred skills whose exclusion improves retrieval quality on unlabeled target-domain data. Agentic experiments on LoCoMo, LongMemEval, HotpotQA, and ALFWorld show that CASS and u-SMCO consistently improve task performance and cross-domain generalization over strong skill-based self-evolving agent baselines. Beyond accuracy, coalition-conditioned reliability modeling reduces sensitivity to noisy outcome-reward fluctuations during reinforcement learning and exposes the limits of isolation-based skill evaluation.

- **研究问题**：一个根本性的可靠性问题被长期忽略——**技能库中积累起来的技能，在被实际调用时，究竟是否真的做出了积极的机制性贡献？**
- **核心发现**：通过对技能库组成与部署域进行系统性审计，论文识别出两种典型的可靠性失效模式：
  1. **联盟污染（Coalition Pollution）**：技能库整体表现提升（bank-level gains）可能掩盖联盟层面（coalition-level）的负面贡献——即新接纳的技能本身贡献近零甚至为负，而实际价值由库中已有技能承担，但结果门控却因整体指标上升而错误保留该技能。
  2. **跨域效用逆转（Cross-Domain Utility Reversal）**：在源域（source domain）上有效的技能，迁移到目标域（target domain）后其贡献方向可能反转，从有益变为有害；而现有方法在迁移时默认技能效益具有跨域不变性，缺乏目标域的观测信号。
- **总体论点**：技能可靠性并非技能的内在固有属性，而是"技能—技能库（联盟组成）—部署域"三者的联合属性。因此，孤立地评估单个技能可靠性会得出误导性结论。

### 2. 方法论：核心技术思想与算法流程

#### 2.1 核心思想

论文提出将技能视为"博弈参与者"，把可靠性分解为**在特定技能联盟与部署域下的环境依赖贡献**。为此引入两个互补的干预模块：

- **CASS（Coalition-Aware Skill Selection，联盟感知技能选择）**：在技能积累/演化阶段使用；
- **u-SMCO（Unsupervised Skill-Masked Coalition Optimizer，无监督技能遮蔽联盟优化）**：在跨域迁移后的部署阶段使用。

#### 2.2 CASS：技能演化阶段的联盟感知选择

- **动机**：传统结果门控（outcome-only gate）仅依据加入候选技能前后的整体奖励变化 \(\Delta = r_{out}(B_{e+1}) - r_{out}(B_e)\) 决定是否接纳，无法区分整体提升源自哪个技能，也无法感知技能间的相互作用。
- **理论依据**：Shapley值边际贡献视角。每个技能的可靠性可用其对所有可能子联盟的平均边际贡献来衡量。
- **机制**：
  1. 以蒙特卡洛方式从候选新技能库中采样多个技能子联盟（coalition），每次采样规模 |S| 在 \(\{1, \dots, k\}\) 上均匀分布；
  2. 计算每个采样联盟的剔除边际（knockout margin）：
     \[
     \Delta_S(B) = \frac{V(B) - V(B\setminus S)}{|S|}
     \]
     即剔除该联盟前后整体价值的差异，并按联盟大小均摊到各成员；
  3. 将 N 个采样联盟边际的平均值 \(\bar{\Delta}_N(B)\) 与原始整体奖励 \(r_{out}(B)\) 线性组合作为排序分数：
     \[
     \sigma(B) = \bar{\Delta}_N(B) + \lambda \, r_{out}(B), \quad \lambda = 0.2
     \]
  4. 该分数替代原始的整体奖励作为候选技能接纳准则，在候选技能不被接受时回滚。
- **关键优势**：因为跨越多个联盟大小进行采样，评分天然捕捉了技能之间的协同（synergy）与拮抗（antagonism），是超越"逐技能独立评分"的联盟级刻画。

#### 2.3 u-SMCO：迁移后的无监督技能遮蔽

- **动机**：跨域迁移时，源域的有益技能可能失效甚至有害，需要一种部署时、无标签信号的甄别与遮蔽机制。
- **特点**：无需目标域任务标签，仅使用目标域未标注查询（unlabeled queries）与原始上下文。
- **评分信号**：采用"检索质量"（retrieval quality）而非任务结果或模型自身偏好：
  \[
  RQ(A) = \frac{1}{|Q_{tgt}|} \sum_{q\in Q_{tgt}} \mathop{\rm mean}_{m \in \text{Top}(q)} \cos(e_q, e_m)
  \]
  其中 \(A\) 为当前保留的技能子集，\(\text{Top}(q)\) 为基于余弦相似度检索到的最相近记忆，\(e_q, e_m\) 分别为查询和记忆的嵌入表示。
- **遮蔽规则**：对每个技能 \(s\) 计算其剔除后检索质量的变化 \(\psi(s) = RQ(B) - RQ(B\setminus\{s\})\)，贪心地移除 \(\psi(s)\) 最小的技能，直到没有技能的得分低于阈值 \(\tau\)。
- **为何不用选择策略熵作为信号**：实验表明代理自身的选择策略熵信号与标签真实效用呈负相关（\(\rho=-0.18\)），因为它继承了训练阶段结果门控的偏差；而基于目标域自身检索质量的信号与真实效用相关性 \(\rho=+0.76\)，显著更高。

#### 2.4 理论结果

论文提出并证明了 **Theorem 1（结果门控不可辨识性，Outcome-Only Non-identifiability）**：仅观测 \(V(B_e)\) 和 \(V(\tilde{B}_{e+1})\) 的门控，即使 \(V(\tilde{B}_{e+1}) - V(B_e)>0\)，也无法判断 \(\tilde{B}_{e+1}\) 中是否包含产生负面贡献的技能。也即，结果门控对联盟层面的交互结构具有结构性的不可辨识缺陷。

### 6. 主要结论与发现

- **可靠性是联盟依赖的**：技能的边际贡献会随其所在联盟的变化而实质性改变（如 insert 在协同技能 capture_contextual_relationships 存在时贡献 +0.084，删除该伙伴后跌至 +0.018），因此不能孤立评估技能。
- **结果门控结构性失明**：门控决策所依赖的奖励边际（≈0.006–0.02）远小于单技能审计的分辨率（≈±0.04），且 Theorem 1 表明这种失效是结构性的，而非统计精度问题。
- **CASS 显著提高接纳质量**：在同样 12 个候选技能上，CASS 只接纳 1 个，MemSkill 接纳了 6 个；而被 MemSkill 接纳的技能整体净效应为负（平均下降 1.38 pp），显示 CASS 有效过滤了联盟污染型技能。
- **u-SMCO 可在无标签条件下检测跨域效用逆转**：它能在 5/6 的银行中识别出源域最有贡献的技能（insert/Skill_IN）恰恰是目标域应该遮蔽的对象，且遮蔽后每个银行表现均提升；对 MemSkill 银行的平均提升（7.17 pp）是对 CASS 银行（3.59 pp）的两倍——说明 CASS 在前置门控中排除的污染正是 u-SMCO 需要在迁移后清理的对象。
- **代理自身的偏好信号不可靠**：选择策略熵反而不如目标域无标签检索质量能指示真实标签效用，这呼应了部分 TTA（test-time adaptation）文献中熵最小化坍缩的观察。
- **整体效果**：相比强基线 MemSkill，CASS+u-SMCO 在单域任务性能与跨域泛化上均有稳定提升（LoCoMo F1 +2.03pp、L-J +1.8pp；LongMemEval 持平；ALFWorld Seen SR +2.09pp、Unseen SR+3.13pp 等）。

### 7. 方法/实验设计上的优点

- **问题切中要害**：提出"技能是否真的起作用"这一基础问题，区分了"功能可用性"与"机制性贡献"，识别出文献中未系统化的两种失效模式。
- **审计先于方法**：先建立系统的可靠性审计框架（SMRA，基于剔除法与 Shapley 视角），再据此设计干预措施，形成了"诊断→干预"的完整闭环，逻辑链清晰、方法论严谨。
- **理论保障**：通过形式化定理证明了结果门控的信息盲区来源，为方法设计提供了理论依据，不只是经验的改进。
- **干预成本可控且即插即用**：CASS 仅改变门控的评分函数，u-SMCO 只需每次部署前运行一次，不影响推理阶段效率，易于作为插件集成到现有自进化代理中。
- **对比公平**：与基线比较时严格保持相同协议——CASS 与 MemSkill 的唯一差异就是门控；u-SMCO 仅在推理前启用，不污染训练过程。
- **跨域信号设计有洞察**：指出"代理自身偏好/熵"不能作为迁移可靠性信号，并提出解耦于训练奖励通道的检索质量信号，实证上相关性从 −0.18 提高到 +0.76。

### 8. 不足与局限

- **跨域规模欠缺**：迁移实验仅采用一个目标域（HotpotQA-50），样本量小、域种类单一，对跨域效用逆转的普遍性支持略显不足。若更多类型的域（如具身域→问答域、多语言域等）得到验证则更利于说服。
- **评估指标依赖 LLM-judge**：主结果中的 L-J 指标本身受评判 LLM 的影响，可能有偏差；缺少针对 judge 的一致性和偏差的详细测量（如与真实标注的一致性报告）。
- **可解释性仍需完善**：高维度共同使用 Shapley 采样进行联盟审计，但没有报告采样数目 N 的敏感性分析，也没有展示不同 N 值下的稳定性边界（文末以限制说明，未在正文实验展示）。
- **未报告失败案例**：未讨论 CASS 拒绝本应接纳的技能或 u-SMCO 遮蔽本应保留技能的失败情况与对应代价分析。
- **成本报告不完整**：虽有 GPU 型号与大致的时间比例，但没有给出不同方法的总训练成本对照数据，也没有与 MemSkill 在完全一致的训练时长与早停策略下的端到端成本对比。
- **结论外推边界需注意**：论文的结论建立在具体文本域技能（记忆操作类技能）上，技能类型相对偏窄，未验证在代码、工具调用等其他技能类别上的可迁移性；对非文本类技能（如参数内化技能）涉及更少。
