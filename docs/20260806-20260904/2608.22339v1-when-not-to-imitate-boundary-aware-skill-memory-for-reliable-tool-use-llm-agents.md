## 摘要
从过去的成功中提取技能对于大型语言模型（LLM）代理的高效进化至关重要。主流的代理自我进化范式通常依赖一个核心假设：为LLM配备源自成功轨迹的技能记忆将单调地提升其问题解决能力。然而，探针分析揭示，仅从成功轨迹中提取技能会使模型陷入“技能模仿陷阱”。对于与过去成功相似但需要不同工具的任务，检索更多技能反而会增强模型对错误工具调用的信心——与无记忆基线相比，程序技能使错误工具的边际增加了47%。为克服这一局限，我们提出“边界感知技能记忆”（BASM），即为每项技能增加明确的边界字段——适用条件、风险提示、回避规则和恢复说明。这些字段将每条检索到的技能从无条件的行为模板转变为状态条件化指导：代理在条件满足时应用技能，在条件不满足时抑制不适用的工具调用，并在执行失败时发出针对性的修复。在三个代理基准和四个模型规模上，BASM始终优于成功蒸馏的技能记忆基线：在AppWorld上任务成功率提升高达23.8%，在BFCL上准确率提升高达5.0%，在AgentDojo上攻击成功率降低4.6%，同时相对于无记忆基线，平均AppWorld步骤数最多减少6.6%。

## Abstract
Extracting skills from past successes is critical for the efficient evolution of Large Language Model (LLM) agents. Prevailing agent self-evolution paradigms typically rely on a core assumption: equipping LLMs with skill memories derived from successful trajectories will monotonically improve their problem-solving capabilities. However, probe analyses reveal that extracting skills solely from successful trajectories traps the model in a \textbf{Skill Imitation Trap}. For tasks that resemble past successes but require different tools, retrieving more skills paradoxically increases the model's confidence in wrong tool calls---procedure skills raise the wrong-tool margin by $47\%$ over a memory-free baseline. To overcome this limitation, we propose \textbf{Boundary-Aware Skill Memory} (BASM), which augments each skill with explicit boundary fields---applicability conditions, risk cues, avoidance rules, and recovery notes. These fields transform each retrieved skill from an unconditional action template into state-conditioned guidance: the agent applies the skill when its conditions hold, suppresses inapplicable tool calls when they do not, and issues targeted repairs when execution fails. Across three agent benchmarks and four model scales, BASM consistently outperforms success-distilled skill-memory baselines: it improves task success rate by up to $23.8\%$ on AppWorld, accuracy by up to $5.0\%$ on BFCL, and reduces attack success rate by $4.6\%$ on AgentDojo, while simultaneously reducing average AppWorld steps by up to $6.6\%$ relative to the memory-free baseline.

## 1. 核心问题与研究动机

LLM 代理在复杂交互环境中的多步工具使用、API 编排和长程规划能力，近年来取得了长足进步。在此背景下，**技能获取（Skill Acquisition）**——即从过去的成功经验中提取、存储和复用可迁移的程序性知识——已成为代理自我进化的重要机制，旨在避免重复探索、将解决结构性相似任务的方案进行跨任务迁移。

然而，本文通过探针分析揭示了一个反直觉的失败模式，称为**技能模仿陷阱（Skill Imitation Trap）**：

- 现有自进化范式普遍假设"更多技能记忆 → 更好决策能力"，即技能记忆具有单调正迁移效应；
- **核心悖论**在于：当任务与既往成功在语义上相似、但需要不同工具时，检索到更多技能反而会放大模型对错误工具调用的偏好；
- 机制层面，成功蒸馏技能会将模型注意力引向程序性内容而非边界线索，使模型把检索到的技能当作**无条件行为模板**执行，而非判断当前状态是否真正满足该技能的适用条件；
- 实验测得，在错误工具状态上，程序技能带来的错误工具边际（wrong-tool margin）相比无记忆基线**上升了 47%**。

根本原因在于：现有技能记忆方法只编码了"如何做"（procedure），而忽略了"何时能做、何时不能做"（boundary）。当语义相关性与决策有效性不一致时，缺乏边界约束的技能检索就会变成一种"不着边际的模仿先验"。

## 2. 方法论：BASM

针对上述问题，论文提出**边界感知技能记忆（Boundary-Aware Skill Memory, BASM）**——一种为技能附加显式边界信息并贯穿"离线构建 → 在线检索 → 决策执行"全链路的技能记忆框架。

### 2.1 核心思想

将每个可复用行为表示为包含七字段的结构化技能：

\[
s = (g, \pi, T, A, R, N, F)
\]

| 组件 | 字段 | 作用 |
|------|------|------|
| 程序性核心（Procedural） | 目标 g、流程 π、工具集 T | 提供技能"怎么做"的可执行知识 |
| 边界组件（Boundary） | 适用条件 A、风险提示 R、规避规则 N、恢复说明 F | 提供技能"何时适用/何时不可用"的上下文证据 |

边界字段 B(s) = A(s) ⊕ R(s) ⊕ N(s) ⊕ F(s)，四条边界插槽各有分工：
- **适用条件**：说明何种状态下可安全调用；
- **风险提示**：识别使语义相似技能变得不安全的观测信号；
- **规避规则**：列举特定状态下应抑制的动作或参数；
- **恢复说明**：局部失败后提供一步修正。

这套架构将检索到的技能从"无条件动作模板"重构为"状态条件化指导"——条件满足则应用，条件违背则抑制，执行偏离则局部修复。

### 2.2 技能库构建（离线阶段）

- **输入**：成功轨迹集 K⁺ 与失败/部分失败轨迹集 K⁻；
- **提取粒度**：步骤级提取（从计划步骤中提取功能技能）与工具级提取（从具体工具调用与观测中提取原子技能）；
- **提取方式**：提取器接收成功上下文用于生成目标、流程、工具字段；失败上下文仅作为边界证据用于生成风险、规避、恢复等字段；
- **校验**：通过确定性验证算符 ψ 强制 JSON 解析、必填字段、列表型边界槽、非空风险/规避规则、工具模式合法性，不合格候选经重试后丢弃或淘汰，保证库中技能均携带可执行的边界证据；
- **精度优先**：宁缺毋滥，优先保证边界特异性而非覆盖率。

### 2.3 检索与提示格式化（在线阶段）

检索得分综合语义相关性、工具重叠度和步/目标重叠度：

\[
\text{score}(x_t, s) = \lambda_{\text{sem}}\cos(e(x_t), e(v_s)) + \lambda_{\text{tool}} \mathcal{J}(T_{x_t}, T_s) + \lambda_{\text{step}}\text{overlap}(x_t, g_s, \pi_s)
\]

关键设计：
- **预算控制提示**：以固定的 token 预算运行提示格式化器——程序化核心字段始终暴露，边界字段仅在边界相关性分数超过阈值 γ 时选择性暴露。这源于探针发现，即不加区分地检索会加剧而非纠正错误工具偏好；
- 格式化为紧凑块：Proc(Sₖ) ⊕ Compress_β({B(s) | s ∈ Sₖ, r_B(xₜ,s) > γ})。

### 2.4 边界检查与运行时修复

- **边界检查器**：将建议工具调用与检索到的边界字段做比较，阻断违反适用性、匹配规避规则或重复已知失败模式的调用；
- **判定机制**：先用确定性字符串/模式检查，遇模糊的自然语言条件再交 LLM 辅助判断；
- **局部修复循环**（用于状态化多轮环境）：当观测 oₜ₊₁ 显示局部失败时，修复模块检索定向提醒 hₜ 注入下一决策步，无需完整重新检索技能。

## 6. 主要结论与发现

1. **技能模仿陷阱客观存在**：仅用成功蒸馏技能时，检索深度增大反而放大错误工具偏好（错误工具边际从 7.31 升至 10.71，+47%），挑战了"更多成功技能记忆 → 更好表现"的核心假设；

2. **BASM 成功克服该陷阱**：将同一状态下的错误工具边际降至 2.26（远低于同长度对照的 5.14–6.60），并翻转了边际随检索深度的上升趋势；

3. **边界字段是因果性抗模仿通道**：敲除边界跨度注意力使受试模型的错误工具偏好回升 +3.45 个 logits，恢复了 69.4% 的过程技能差距；程序跨度与随机同长度掩码均无此效果，证明特定于边界通道；

4. **效果随状态而调节，而非全局保守化**：注意力边界/程序比例在 Tok 仅 0.15，Twrong 升至 1.23，Trepair 达到 1.81；敲除实验选择性提升 Twrong-wrong 边际（+0.27）而不影响 Twrong-correct（+0.04）甚至略微降低 Tok-correct（−0.11），证明并非对工具使用的一刀切惩罚；

5. **基准级别一致性提升**：BASM 在 AppWorld 上将成功率提升至 76.19%（Qwen3-32B，较 Proc. Skill 提高 10.12 个百分点）；BFCL 总体精度最高达 53.75（Qwen3.5-397B-A17B）；AgentDojo 上在 Qwen3-14B 实现效用与安全的帕累托改进，ASR 降至 2.95%；

6. **效率同步改善**：AppWorld 平均步数较无记忆基线最多缩减 6.6%，说明改进并非依靠更长的交互轨迹。

1. **发现新颖、可操作**：从机制上揭示"成功经验蒸馏 → 盲目模仿"的失效模式而非仅提出启发式修补，"何时不应模仿"的视角敏锐；
2. **机制解释深度突出**：综合运用注意力归因、logit 边际、同提示敲除、逐头定位、线性探针等多重诊断手段，因果关系搭建相对严密，比起许多仅报端到端指标的工作可信度更高；
3. **方法设计优雅且维度全面**：七字段技能模式将"边界意识"嵌入库对象而不仅是提示模板；三阶段（离线构建、在线格式化、运行时执行）统一贯穿，层级完整；
4. **效率与安全并重**：不仅报告任务成功率，还同时关注平均交互步数（效率）、攻击成功率（安全），使基线全面；
5. **公平对照相当严谨**：多种等长填充与配对对照削弱了替代解释，促使结论更具说服力。

## 8. 不足与局限

**（1）实验数据规模与精度**：
- AppWorld 测试集 168 任务、BFCL 三子集容量有限，判定差距的统计置信度未报告；
- 大规模模型上的优势幅度较为微弱，可能影响外部效度。

**（2）安全评估覆盖面单一**：
- AgentDojo 安全测量只围绕提示注入攻击，未扩展至工具滥用、数据泄露、后门触发等其他安全维度，结论不宜泛化为通用安全增益。

**（3）方法本身的适用边界**：
- 边界字段依赖自然语言表达，增加了上下文 token 占用，在极低预算环境下需要压缩权衡；未能展示适应不同预算的边界表示策略；
- 技能提取质量依赖上游 LLM 的提取能力与失败轨迹的可用性，如果失败样本不足（冷启动或新领域），边界字段可能有缺失或幻觉；
- 确定性校验只能保证格式，难以保证边界语义的确切性。

**（4）理论层面**：
- 线性探针的负面结论虽被解释为"动态注意机制"的佐证，但这一点缺乏对应正面对照来有力支撑该解释的排他性。

**（5）其他信息缺口**：
- 硬件配置、推理成本、技能库构建时间等工程资源指标未披露，限制复现和成本评估。

## 9. 总结

BASM 以"技能必须携带其有效性边界"为核心洞见，系统性地指出了成功蒸馏式技能记忆的潜在危险，并通过设计出端到端的**程序性内容 + 边界字段**结构化检验管线，将技能复用从盲目模仿转变为带有效性约束的受控迁移。其方法论框架与实验证据链的完整性在同类工作中较为少见，对 LLM 代理记忆/自进化研究提供了较高质量的经验性参考和可复用的设计要素。
