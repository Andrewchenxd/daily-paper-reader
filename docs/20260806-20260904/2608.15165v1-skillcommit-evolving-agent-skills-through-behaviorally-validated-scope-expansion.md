## 摘要
大型语言模型（LLM）代理可以通过将历史经验转化为可复用的程序性知识而无需更新参数地持续改进。然而，现有方法往往基于语义相似性或LLM判断来整合经验，这可能合并表面上相关但在行为上不相容的策略，从而降低性能。为解决这一问题，我们提出SkillCommit，一种在线技能演化框架，将持续经验转化为分层可复用技能库。每条新经验首先作为实例特定的补丁被保留，保留在其局部上下文中经过行为验证的内容。随着相关技能的积累，SkillCommit将那些共享共同行为机制的技能抽象为更高级别的技能。具体来说，对于每个传入技能，基于嵌入的检索首先识别候选相关技能。跨实例回放和基于LLM的机制检查确定这些技能是否在案例间可迁移并共享共同的底层机制。通过两项检查的候选技能被抽象为更高级别的技能，并且仅当它保留所有组成技能的经过验证行为时才被提交。在RuleArena、OpenExempt和KOR-Bench上的实验表明，SkillCommit在不同领域持续提升代理性能。此外，学习到的技能可在不同模型规模和系列间迁移，实现跨模型经验迁移。

## Abstract
Large language model (LLM) agents can continually improve without parameter updates by converting historical experience into reusable procedural knowledge. However, existing methods often consolidate experience based on semantic similarity or LLM judgments, which may merge superficially related but behaviorally incompatible strategies and thereby degrade performance. To address the issue, we propose SkillCommit, an online skill evolution framework that continuously transforms experience into a hierarchical library of reusable skills. Each new experience is initially preserved as an instance-specific patch, retaining the behavior validated in its local context. As related skills accumulate, SkillCommit abstracts those sharing a common behavioral mechanism into higher-level skills. Specifically, for each incoming skill, embedding-based retrieval first identifies candidate related skills. Cross-instance replay and an LLM-based mechanism check determine whether these skills transfer across cases and share a common underlying mechanism. Candidates that pass both checks are abstracted into a higher-level skill and committed only if it preserves the validated behavior of all constituent skills. Experiments on RuleArena, OpenExempt and KOR-Bench demonstrate that SkillCommit consistently improves agent performance across diverse domains. Moreover, the learned skills transfer across model scales and families, enabling cross-model experience transfer.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）代理能否在不更新参数的情况下，通过积累的经验持续提升自身能力？现有的“技能演化”（Skill Evolution）方法虽然能将历史轨迹转化为可复用的经验（如insight、patch等），但它们在整合经验时过于依赖语义相似性或LLM自身的判断，而**忽略了行为层面的兼容性**。
- **研究动机**：语义上相似的策略可能在行为上相互冲突，而语义上不同的策略可能共享相同的底层机制。现有方法在形成高层技能时，若错误合并了行为不兼容的策略，或将局部经验过度泛化到不支持的范围，会导致性能下降（负迁移），甚至比不使用任何经验时表现更差。
- **整体含义**：论文提出，可靠的技能演化必须建立在**“行为验证”（Behavioral Validation）**之上。每一次将知识的适用范围从“单一实例”推广到“一组实例”或“更高抽象层级”，都必须有重放（Replay）证据作为支撑，以确保经验复用不会破坏已得到验证的正确行为。

### 2. 论文提出的方法论：核心思想与关键技术

**核心思想**：将技能库的构建视为一系列**“行为验证过的范围扩展”**（Behaviorally Validated Scope Expansions）过程。每个候选技能必须通过严格的本地验证，其适用范围的扩大也必须经过回放证据检验。

SkillCommit框架包含三个关键阶段，其整体流程如下图所示：

- **阶段一：反馈引导的补丁归纳（Feedback-Guided Patch Induction）**
    - **目的**：将单次失败经验转化为**实例特定（instance-specific）**的补丁，并验证该补丁对该任务有效。
    - **过程**：当执行器（Executor）在任务上失败时，一个具备特权信息（正确答案）的教师模型通过分析法失败与成功轨迹的差异，生成候选补丁（程序性指导）。随后进行 **源重放验证（Source-replay Validation）**，让冻结的执行器在原始任务上使用该补丁运行，若任务验证器判定成功，则补丁被接纳。
    - **关键点**：该过程最多尝试K=3次；需要防止最终答案或特定解法泄露，以维护泛化能力。

- **阶段二：行为兼容性分组（Behavioral Compatibility Grouping）**
    - **目的**：判断一个局部有效的补丁，能否安全地扩展到其他实例（即扩展现有技能或形成新技能）。
    - **方法**：
        1.  **候选检索**：通过嵌入向量的语义相似性，找到最可能的候选现有技能或残余补丁（R=4），作为后续行为验证的“待筛选集”。
        2.  **跨实例重放（Cross-instance Replay）**：采用双向验证，计算行为兼容性分数 `C(p, qt)`。公式综合考虑了“现有技能能否解决新补丁的源任务”和“新补丁能否解决现有技能覆盖范围的任务”。
            $$C(p, q_t) = \frac{\rho(p, x_t) + \sum_{x_j \in W(p)} \rho(q_t, x_j)}{1 + |W(p)|}$$
        3.  **机制检查（Mechanism Assessment）**：通过重放获取分数后，LLM作者会判断两个候选是否共享相同的底层机制。重放与机制检查双项通过，方可确认行为兼容。如果没有兼容技能，则尝试寻找锚点补丁与同组补丁进行交叉验证，形成新技能群体。

- **阶段三：源保留整合（Source-Preserving Consolidation）**
    - **目的**：在将多个兼容补丁或兼容技能扩展抽象为更高层技能时，确保抽象过程**不丢失**原实例已验证过的行为。
    - **方法**：在技能作者（不能看到源问题和标准答案）基于工具生成高层技能抽象（包含`when`/`repair`/`avoid_when`）后，进行 **全范围源重放（Full-Scope Source Replay）**。
    - **提交与分裂机制（Commit/Split/Reject）**：只有在所有源实例上重放均成功的候选才会被提交。若只在部分实例上成功，则进行“分裂”，限制其声明范围至重放支持的那些实例。若总是失败，则拒绝该抽象。

### 8. 不足与局限

- **计算开销较大**：行为验证逻辑中包含了大量的重放循环（源重放、交叉实例重放、全范围源重放、迭代重放），虽然是零参数训练，但其针对每次具体操作调用的API成本及计算资源消耗会显著高于无重放的现有技术。
- **对“教师模型”的依赖**：需要依赖具备特权信息（标准答案、裁判）的强黑盒教师模型来诊断并生成补丁的作者。如果教师模型不够强，或反馈质量不高，提取到的初始补丁将难以有效帮助提升下游模型能力。
- **在后台处理中仍需依赖语义模块**：尽管主要是通过行为信息做最终决策，但流程中仍需依赖嵌入相似度或语义检索来筛选候选者，这将影响其对于被语义屏蔽但行为上存在关联的策略的挖掘潜力。
