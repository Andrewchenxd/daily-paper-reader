## 摘要
跨多样任务高效改进自主智能体对于加速智能体AI中的递归自我改进（RSI）至关重要，提示优化已成为一种有前景的方法，能够提供与微调模型权重相当的性能提升，同时降低优化和服务阶段的计算成本。然而，近期的发展越来越倾向于不必要的复杂提示优化器。我们引入了朴素提示优化（NPO），这是一种轻量级的单谱系方法，利用教师模型和展开反馈迭代修订提示。NPO以更少的展开次数实现了与GEPA相当或更好的性能，并且其优势随着教师模型更强而增加，这表明更强的教师推理能力可以部分替代优化器端的搜索复杂性。在交互式游戏中，NPO总体保持与GEPA的竞争力，而GRPO在部分不太适合提示优化的任务上表现更好。我们还表明，当NPO优化后的提示被原样应用于其他学生模型时，能引发类似的性能提升，尤其是在同一系列模型之间。总体而言，我们的初步结果表明，简单、线性的提示优化可以与显著更复杂和精密的搜索过程相媲美。

## Abstract
Efficiently improving autonomous agents across diverse tasks is central to accelerating recursive self-improvement (RSI) in agentic AI, with prompt optimization emerging as a promising approach capable of delivering performance gains comparable to those achieved by fine-tuning model weights, while reducing computational costs in both optimization and serving. However, recent developments increasingly favor unnecessarily complex prompt optimizers. We introduce Naive Prompt Optimization (NPO), a lightweight single-lineage method that iteratively revises prompts using a teacher model with rollout feedback. NPO achieves comparable or better performance than GEPA with fewer rollouts, and its advantage increases with stronger teacher models, suggesting that stronger teacher reasoning can partially substitute for optimizer-side search complexity. In interactive games, NPO remains broadly competitive with GEPA, while GRPO performs better on some tasks less amenable to prompt optimization. We also show that NPO-optimized prompts elicit similar performance improvements when applied verbatim to other student models, especially across models within the same family. Overall, our preliminary results show that simple, linear prompt optimization can rival substantially more sophisticated and complex search procedures.

### 1. 核心问题与研究动机

- **研究背景**：在智能体AI中，如何高效改进自主智能体的性能，是加速递归自我改进（RSI）的关键路径。提示优化（Prompt Optimization）提供了一个极具吸引力的方向：它无需更新模型权重，仅通过改进指令文本（prompt）就能获得与微调相当的收益，且能以轻量、可迁移的方式在部署阶段通过第三方推理API随时适配，避免用户/任务专属权重的维护和部署成本。
- **核心问题**：近年来自动提示优化器（如OPRO、ProTeGi、MIPRO、GEPA）设计得日趋复杂，引入了束搜索、贝叶斯优化、多智能体池、帕累托筛选等复杂机制。论文提出的核心质疑是：**这类复杂的搜索过程/算法机制是否真的必要？**
- **整体主张**：作者提出一种“朴素”的单系提示优化方法NPO——仅维护一条提示谱系，由教师模型基于rollout轨迹迭代修订提示，不使用任何复杂搜索。论文用数据证明：**更强教师模型的推理能力，可以部分替代优化器端的搜索复杂度**——简单线性方法就能与复杂搜索方法相媲美甚至更优。

### 2. 方法论

- **核心思想**：NPO遵循"LLM-as-optimizer"框架（源自OPRO），但关键区别是反馈信号的丰富度——NPO向教师模型提供**完整的轨迹级信息**（rollout traces 与逐条reward），而非像OPRO那样仅提供提示对与标量分数。该方法维持**单条提示谱系**，不做候选池管理、不做帕累托筛选、不做束搜索。
- **技术细节**：
  1. 迭代流程：在第i轮，用当前提示P(i)在学生模型上执行N次rollout；将所有提示、轨迹、奖励打包成反馈上下文；让教师模型据此修订出下一版本P(i+1)。
  2. **滑动窗口反馈（Sliding-Window Feedback）** ：为控制上下文长度并保留时序信息，算法对当前版本及最近W−1个历史版本的提示与轨迹构建窗口，一并送入教师模型。窗口大小在实验设定中取W=2。
  3. 算法流程（伪代码级）：
     ```
     for i = 0 to Y−1:
       采样大小为N的minibatch Bi
       用P(i)在Bi上执行rollout，收集轨迹Ri与奖励
       构造滑窗反馈∪{Rj}（j从max(0,i−W+1)到i）
       由教师模型T基于（P(i) + 历史反馈）生成下一个提示P(i+1)
     返回提示序列{P(0)...P(Y)}及最佳候选
     ```
- **与既有优化的区别**：GEPA保持多候选池、每轮用父提示+反射生成子提示，经验证集评估后再做帕累托选择，步骤繁复；NPO则完全线性推进，纯粹依赖教师模型的推理和反馈丰富度来优化提示。GRPO则是权重微调基线，在固定提示和backbone上训练LoRA模块，组内相对Normalization计算优势。

### 6. 主要结论与发现

- **结论①（核心）** ：在IFBench和HotpotQA上，NPO以低于GEPA的rollout总预算取得了与之相当甚至更高的峰值性能。提示优化性能的关键可能更多来自**教师模型的推理能力和反馈信号的信息丰富度**，而非辅助搜索复杂度。
- **结论②（教师强度依赖）** ：NPO的收益随教师模型增强而明确增长——GPT-5.5 + NPO收敛迅速且峰值最高；相比之下，GEPA从强教师获益较小（如GEPA+GPT-5.5只是与GEPA+Qwen3-8B基本持平）。这支持"强教师推理可部分替代优化器搜索机制"的核心论点。
- **结论③（跨学生迁移）** ：在Qwen3-8B上优化的提示不带修改地直接用于Qwen3-14B/32B、Llama-3.1/3.3-70B，普遍带来性能增益，尤其同族迁移效果更明显；跨族迁移虽略弱，但大多数组合也都呈正增益。
- **结论④（TextArena基准）** ：22个游戏中，NPO与GEPA综合表现基本持平、互有胜负，未出现GEPA全面胜过NPO的局面；GRPO在部分提示优化不太见效的任务上提供互补优势，但也非全面胜出。
- **结论⑤（避免泄漏）** ：对优化提示做gold-answer重叠检测，发现与训练集答案的重叠正常增长，而与验证集答案几乎零重叠；残余少量非同题同答案重叠，排除验证集泄漏造成的虚假提升。
- **总结论**：简单、线性、无复杂搜索的提示优化法可作为稳健基线，实际上能媲美复杂得多的高级提示搜索/RL微调流程——反映了自优化领域"简单+强模型"的设计哲学，对用户级提示优化和递归自改进工程有直接启示价值。

- **方法简洁且工程部署轻**：仅单一谱系 + 一次教师生成调用；无候选池、无反射选择、无验证集启发式。对实际系统低延迟、易维护，对自助提示优化框架的落地友好。

### 8. 不足与局限性

- **任务覆盖面偏窄**：只在少量任务类型上验证，未涉及超长程、开放式、类Agent中长期自主规划任务——论文也承认后续需更复杂的agent环境验证。
