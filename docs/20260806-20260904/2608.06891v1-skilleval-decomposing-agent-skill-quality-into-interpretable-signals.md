## 摘要
智能体技能提供可复用的程序性知识，帮助智能体解决专门的任务。随着技能使用范围的扩大，评估技能质量变得日益重要。现有评估通常通过测试技能是否能提升特定下游任务的性能来衡量技能质量。然而，可复用的技能可能适用于多个任务场景。下游评估主要反映技能与被评估任务之间的兼容性，仅提供技能质量的部分视角，且无法指出技能中应改进的方面。我们发现 \texttt{SKILL.md} 文档的一般属性在技能质量中发挥重要作用。为评估这些属性，我们提出 \textbf{SkillEval}——一个可解释的文档级技能评估框架。SkillEval 使用固定且可检查的评分方向评估每个属性，产生可解释的分数。它进一步度量并降低了不相关文档特征（如长度和格式）的影响，使每个分数更具体地捕获其预期的语义属性。具体而言，SkillEval 从模型隐藏表示空间中的受控正负技能对中学习每个质量属性的可解释方向，并将新技能的表示投影到这些固定方向上来进行评分。我们使用 SkillEval 在受控质量测试中评估技能，结果表明 SkillEval 能可靠地区分不同质量的技能。此外，SkillEval 的分数紧密反映下游任务表现，提供技能是否可能帮助智能体完成任务的早期指示。我们进一步探索 SkillEval 用于诊断技能文档的弱点并指导有针对性的修订。修订后的技能改善了目标属性，并在下游任务上获得了更高的通过率。

## Abstract
Agent skills provide reusable procedural knowledge that helps agents solve specialized tasks. As their use expands, evaluating skill quality becomes increasingly important. Existing evaluations often measure skill quality by testing whether a skill improves performance on specific downstream tasks. However, a reusable skill may apply to multiple task scenarios. Downstream evaluation mainly reflects the compatibility between a skill and the evaluated task, provides only a partial view of skill quality, and does not identify which aspect of the skill should be improved. We find that general properties of the \texttt{SKILL.md} document play an important role in skill quality. To evaluate these properties, we propose \textbf{SkillEval}, an interpretable framework for document-level skill evaluation. SkillEval evaluates each property using a fixed and inspectable scoring direction, producing interpretable scores. It further measures and reduces the influence of unrelated document features, such as length and formatting, so that each score captures its intended semantic property more specifically. Specifically, SkillEval learns an interpretable direction for each quality property from controlled positive--negative skill pairs in the hidden representation space of the model, and scores a new skill by projecting its representation onto these fixed directions. We use SkillEval to evaluate skills in controlled quality tests and show that SkillEval reliably distinguishes skills of different quality. In addition, SkillEval scores closely reflect downstream task performance, providing an early indication of whether a skill is likely to help an agent complete a task. We further explore SkillEval for diagnosing weaknesses in skill documents and guiding targeted revisions. The revised skills improve the targeted properties and achieve higher pass rates on downstream tasks.

### 一、论文的核心问题与整体含义

- **研究背景**：智能体技能（Agent Skills）是可复用的程序性知识文档（通常以 SKILL.md 形式存在），帮助智能体在推理时获得任务知识、工具使用方法和流程指引。随着技能在智能体生态中的广泛使用，如何评估技能质量愈发重要。
- **核心问题**：现有评估（如 SkillsBench 等）主要依赖下游任务执行结果（任务通过率）来判断技能好坏。但作者指出这种评估方式存在三个关键缺陷：
  1. 下游评估结果高度依赖于技能与特定被评估任务之间的兼容性，只能反映技能质量的一个方面；
  2. 单一下游通过率无法解释技能中到底是哪个属性出现了问题；
  3. 良好技能应支持多种任务场景，单任务评估无法反映其可复用的普适质量。
- **核心论点**：SKILL.md 文档的固有属性（如触发条件清晰度、内容一致性、执行指导质量等）本身是技能质量的重要决定因素，可以用一种不依赖下游执行的、可解释的文档级评估方式来衡量。

### 二、方法论

SkillEval 是一个可解释的文档级技能评估框架。其核心流程可以概括为：将技能文档表示映射到模型隐藏空间中，通过与各质量维度对齐的固定方向进行投影打分。核心步骤包括维度定义、数据构建（用于学习方向）、表示提取与方向学习，以及打分与标准化。

1. **质量维度分解**：将技能质量划分为四个互补维度、共七个指标：
   - **可应用性（Applicability）**：A1（格式合法性，用确定性规则检查）、A2（触发条件清晰度）；
   - **内容质量（Content Quality）**：B1（内容一致性）、B2（技术具体性）；
   - **执行指导（Execution Guidance）**：C1（工作流完整性）、C2（输入输出明确性）；
   - **鲁棒性（Robustness）**：D1（失败感知能力）。
   - 其中 A1 用规则判定，其余六个均为语义指标，通过学习得到。

2. **可控正负技能对构建**：对于每个语义指标 Fᵢ，选取满足该指标的正样本 d⁺，通过一个指标特定的操作函数 Tᵢ 生成其负样本 d⁻ = Tᵢ(d⁺)。构造过程中保持任务目标、主题、工具、长度、结构等非目标属性尽量不变，确保两个技能的主要差异集中在目标质量属性上。

3. **隐藏表示提取与方向学习**：
   - 使用冻结的 Qwen3.5-9B 模型，从第 16 层隐藏状态中提取 token 级表示；
   - 每个指标定义独立的池化策略：
     - A2 使用 frontmatter 描述部分的均值池化；
     - B1 对描述和正文的均值池化表示取平均；
     - B2、C1、C2 对正文作均值池化；
     - D1 使用完整输入最后一个 token 的表示。
   - 对每对正负样本，计算表示差异 Δᵢ,j = hᵢ(d⁺ᵢ,j) − hᵢ(d⁻ᵢ,j)。
   - **混淆方向消除**：将每个差异向量投影到预测的混淆单位方向 u_conf 上并从原向量中扣除，以去除长度、格式等因素带来的偏置影响。
   - **指标方向**：对各正交化后的差异向量取平均并归一化，得到单位方向向量 bᵢ。

4. **打分与标准化**：
   - 给定新技能 d，指标得分 sᵢ(d) = hᵢ(d)ᵀ bᵢ；
   - 使用训练集中的正负样本得分的均值与标准差进行 z-score 标准化，得到最终分数 zᵢ(d)，正值表示与正样本对齐。

5. **关键特性**：评估时各指标方向保持固定，不需要调用生成式 LLM 作为裁判，具备可审计性、可复现性，同时具备可解释性。

### 六、主要结论与发现

1. **可靠性**：SkillEval 在验证集上能明确区分正负技能——六个指标的均值得分间隔从 C1 的 0.75 到 A2 的 1.94 不等；所有指标的正技能得分均大于零、负技能均小于零。

2. **与下游任务效用的相关性**：五个指标（B1、B2、C1、C2、D1）的得分与下游 pass-rate uplift 高度正相关，Pearson r 在 0.779–0.787 之间；全部指标联合模型的 r=0.716。

3. **诊断与改进能力**：在技能修订实验中，SkillEval 引导的修订相比原始技能提升下游通过率 29.5 个百分点（从 18.6% 到 48.1%），相比无引导修订（LLM-only，38.3%）高出 9.8 个百分点；且各项指标分数同步提升。

4. **偏差控制**：各指标得分与文档长度、格式等表面变量大多呈弱相关（B2 与长度有中等负相关 r=-0.355），表明得分主要反映语义属性；方法支持进一步正交化解耦。

5. **鲁棒性**：跨不同骨干模型（Qwen、Llama 两族）的得分相关性较高（0.811–0.948），说明评分信号在骨干模型替换下基本稳定。

6. **下游评估的局限**：同一技能在不同下游任务上的提升差异巨大（最高达 66.7 个百分点），说明单任务评估无法替代文档级质量评估。

7. **隐藏层和池化策略选择因指标而异**：第 16 层对所有指标均有效但不是每个指标最优，池化策略也各有优劣——全均值池化利于 A2/B1，末 token 池化利于其余指标。

### 七、优点

- **思路新颖**：首次将“表示方向”范式系统应用于技能文档的细粒度质量评估领域。
- **可解释性好**：不同于黑箱 LLM 裁判，每个维度都有独立的固定方向，能定位技能文档的具体弱点。
- **可复现性强**：评估过程基于固定方向和已冻结模型，不依赖随机生成的裁判调用；同一技能文档反复评分结果稳定。
- **偏差控制机制完整**：预计算混淆方向、正交化去除无关因素影响，并提供系统化的偏差诊断方法，提升了评分的语义纯净度。
- **多维质量画像**：从四个互补维度分解质量，而不是输出一个总分数，提供了更全面的质量信息。
- **验证和消融系统化**：从正负样本区分、下游相关性、隐藏层选择、池化策略、骨干模型替换、下游模型稳定性等多个角度对框架进行了验证。

### 八、不足与局限

- **算力与资源信息披露不足**：论文未提及训练和评估所使用的 GPU 型号、数量及时间。
- **无独立评估基线**：没有与现有替代方案（如 LLM-as-a-judge、rule-based 评估等）进行系统性横向对比。

- **指标间区分度不平衡**：C1（工作流完整性）和 C2（I/O 明确性）的正负样本区分度较低（AUROC 仅 0.70/0.72），存在改进空间。

- **数据时效性**：文中引用了 2026 年的模型和方法（如 Qwen3.5、GPT-5.5），前沿性较强但有快速过时的风险。
- **数据集构建的复杂性**：LLM 生成正负技能对之间存在筛选标准的潜在主观性，实验中对 LLM 判断一致性的检查不够充分。
