## 摘要
大语言模型智能体通过在日常任务中不断积累程序性知识到技能中，变得越来越适应这些任务。这些技能是轻量级、可重用的文本制品，被加载到智能体的上下文中，而无需更新权重。近期的方法通过迭代任务执行、故障诊断和轨迹引导的文本空间更新来改进技能。然而，现有框架缺乏明确的诊断——结果反馈，并将删除视为一种通用的编辑操作，而不是一种专门用于整合积累知识的机制。我们提出了SkillProx，一种受近端梯度启发的正向-反向框架，它结合了闭环诊断演化与效用感知的近端精炼。受平衡任务损失与技能复杂性的复合目标的驱动，正向阶段在同一任务批次上重新执行诊断驱动的编辑，回滚回归现象，并将测量结果反馈到后续诊断中。反向阶段将产生的技能分解为可审计的知识单元，使用冻结的留一法效用审计来估计它们的贡献，并应用验证门控的整合、降级或移除。在跨多个骨干大语言模型的分布内和分布外基准测试上的实验表明，SkillProx相比最强的基于梯度的基线，平均准确率提高了3.0个百分点。组件消融实验展示了闭环诊断与近端精炼的互补效应。

## Abstract
LLM agents increasingly adapt to recurring tasks by accumulating procedural knowledge in skills. These skills are lightweight, reusable textual artifacts that are loaded into the agent's context without weight updates. Recent methods refine skills through iterative task execution, failure diagnosis, and trajectory-guided text-space updates. However, existing frameworks lack explicit diagnosis--outcome feedback and treat deletion as a generic edit operation rather than a dedicated mechanism for consolidating accumulated knowledge. We introduce SkillProx, a proximal-gradient-inspired forward--backward framework that couples closed-loop diagnostic evolution with utility-aware proximal refinement. Motivated by a composite objective balancing task loss and skill complexity, the forward stage re-executes diagnosis-driven edits on the same task batch, rolls back regressions, and feeds measured outcomes into subsequent diagnoses. The backward stage decomposes the resulting skill into auditable knowledge units, estimates their contributions using a frozen leave-one-out utility audit, and applies validation-gated consolidation, demotion, or removal. Experiments on in-distribution and out-of-distribution benchmarks across multiple backbone LLMs show that SkillProx improves average accuracy by 3.0 percentage points over the strongest gradient-based baseline. Component ablations demonstrate the complementary effects of closed-loop diagnosis and proximal refinement.

## 1. 核心问题与研究动机

**背景与问题链：**

- 大语言模型（LLM）智能体在解决复杂任务时，越来越依赖将程序性知识外化为**技能（skills）**——一种轻量级、可重用的文本制品，在推理时被加载进模型上下文，无需更新任何权重。
- 早期研究聚焦于**技能合成**（从演示、成功轨迹、外部文档一次性构建技能），但 SkillsBench 等基准表明一次性合成技能在不同任务上收益极不均衡，甚至产生负增益，因为一次构建无法预知后续遇到的多样情境。
- 为此，近期工作转向**技能自我演化**（skill evolution），代表方法如 SkillGrad 将任务失败视为“文本梯度”，通过诊断失败原因并直接提交补丁来迭代修改技能。
- SkillProx 识别出现有技能演化方法的两大关键缺陷：
  1. **未经验证的前向更新（Unverified forward updates）**：LLM 生成的诊断被默认当作有效更新方向，补丁提交后既不重新执行测量效果，也不将该效果反馈给后续诊断——即“开环”操作。
  2. **无监管的技能增长（Unregulated skill growth）**：迭代打补丁不断扩充技能内容，却缺乏对已积累知识的重新评估机制；技能中可能累积重复指令、冲突启发式或误推广的任务特定解法，干扰有用知识并增加文本复杂度。

**核心研究问题：**
> 如何将“基于结果验证的前向诊断”与“基于结构感知的后向精炼”相结合，使技能的任务能力与其积累的结构共同演化（co-evolve）？

**经验动机（Motivation）：**

- 作者实验发现：仅凭诊断文本的语义合理性无法判断更新质量；在相同任务批次上重执行更新后的技能，能直接揭示更新是有益还是有害（开环准确率 50.30±2.50 vs 闭环 51.40±1.51）。
- 留一法（leave-one-out）评估发现，已积累的知识单元中存在负效用内容，移除它们可将 OJ hard 准确率从 46% 提升到 54%，说明应通过选择性整合而非持续增长来维护技能健康。

## 2. 方法论

### 2.1 总体框架：受近端梯度下降启发的正反向优化

SkillProx 将技能演化形式化为**复合优化问题**：

\[
\min_{X \in \mathcal{X}} J_\lambda(X) := L_T(X) + \lambda G(X), \quad \lambda \ge 0
\]

其中 \( L_T(X) \) 为任务的期望损失，\( G(X) \) 为技能文本复杂度（SKILL.md 及引用文件总字符数），λ 为性能与复杂度间的权衡系数。该式用于提供概念化基础而非被显式优化。

类比标准近端梯度下降（PGD）——前向执行梯度步、后向执行近端算子——SkillProx 将其映射到离散文本空间：

| PGD 组件 | SkillProx 对应实现 |
|---|---|
| 前向方向 \(-\nabla f(x)\) | 从任务轨迹推断自然语言编辑方向 |
| 前向更新 \(v_k = x_k - \eta \nabla f(x_k)\) | 诊断→补丁→同批重执行→拒收反馈→回滚 |
| 后向近端步 | 冻结效用审计、语义精简、结构校验、验证门控 |
| 距离惩罚 \(\|x-v\|^2/(2\eta)\) | 局部单目标编辑 + 软压缩上限 ρ |
| 收缩强度 \(\eta\lambda\) | 由 τ、δh、δc、ρ 分别控制 |

### 2.2 前向阶段：闭环诊断演化（Closed-Loop Forward Update）

在迭代 k，当前技能 Xk 在训练批次 Bk 上执行：

1. **诊断器（Diagnostician）** 利用失败轨迹、对比性成功轨迹、近期历史、上一尝试的拒收原因，提出编辑方向。
2. **补丁器（Patcher）** 从同一迭代初始快照生成候选技能 \( \tilde{X}_k^{(j)} \)。
3. **同批重执行**候选技能，并按**接受门控**（Eq. 5）决定是否提交：

\[
\text{Gate}_{\text{fwd}}(\tilde{X}_k^{(j)}) = \mathbb{1}[H_{B_k}(\tilde{X}_k^{(j)}) \ge H_{B_k}(X_k)] \times \mathbb{1}[C_{B_k}(\tilde{X}_k^{(j)}) \ge C_{B_k}(X_k)]
\]

即要求硬准确率（hard accuracy）和平均单元格准确率（mean cell accuracy）均不下降。

- 第一个实现**严格硬准确率提升**的候选提前终止搜索；若无严格提升，最多尝试 3 次，取硬/细胞准确率字典序最优的候选，仍需满足 Eq. (5)；否则迭代保持 Xk 不变。
- 被拒尝试的硬/细胞变化量及尝试方向将注入下一次诊断，形成跨迭代的接受/拒绝语义历史。
- 该门控仅约束当前批次，不隐含跨迭代、验证集或测试集上的单调性。

### 2.3 后向阶段：冻结效用审计与验证门控近端收缩（Prox）

1. **单元分解**：将前向输出的技能 Xf 解析为可审计的 L2 章节和 L3 引用组：\( Q(X_f) = \{q_1, q_2, \ldots, q_n\} \)。
2. **冻结留一法效用审计**（Eq. 7）：对每个单元 qi，完全移除后重新评估，边际效用定义为

\[
u_i^{\text{hard}} = H_V(X_f) - H_V(\text{Ablate}(X_f, q_i)), \quad
u_i^{\text{cell}} = C_V(X_f) - C_V(\text{Ablate}(X_f, q_i))
\]

   正值表示移除会降低性能（有用），负值表示移除后表现更好（有害）。所有效用在前向结束后一次性测量并保持冻结。
3. **候选选择与排序**（Eq. 8）：候选集为 \( I_\tau = \{i: u_i^{\text{cell}} < \tau\} \)，默认 τ=−0.001；候选按 (cell 效用, hard 效用) 字典序升序处理。
4. **Shrinker 生成试验编辑**：对当前技能副本执行三种操作之一——**整合**（consolidate，将可泛化内容并入最相关章节后删除目标）、**降级**（demote，将过细 L2 内容移入 L3）、**移除**（remove，删除完全冗余或误导内容）。
5. **门控条件**（Eq. 9–10）需同时满足：
   - 结构有效且复杂度严格下降：\( \text{StructOK}(T_m)=1 \)，\( G(T_m) < G(X^{(m)}) \)
   - 验证集硬准确率不降：\( H_V(T_m) \ge H_V(X^{(m)}) - \delta_h \)，δh=0
   - 细胞准确率降幅有界：\( C_V(T_m) \ge C_V(X^{(m)}) - \delta_c \)，δc=0.02
   - 累积压缩未超软上限：\( 1 - G(X^{(m)})/G(X_f) < \rho \)，ρ=0.10（软帽，而非最终输出的严格上限）
6. **单遍处理**：每个候选最多处理一次；若之前的整合已移除其目标则跳过。试验编辑先应用在副本上，拒绝则丢弃，接受则替换当前技能。

**理论性质**：候选集有限、每次接受必严格降低文本复杂度，收缩保证有限步终止；记录到的验证集硬准确率不降、细胞准确率最多累计下降 R·δc（R 为接受编辑数）。评估复杂度为 O((n+M)|V|)。这些性质不构成对测试集的单调性保证或经典 PGD 收敛性保证。
