## 摘要
基于LLM的多智能体系统在复杂任务上表现出强大的性能，但从交互经验中持续改进仍然具有挑战性。现有的自我反思方法构建经验记忆，但这些记忆大多难以调用、改进或扩展，而智能体技能提供了一种更具操作性的单元：结构化的程序性知识，规定了何时行动、如何行动以及使用哪些资源或工具。我们提出了MASkills，一种通过智能体技能优化多智能体LLM系统的持续学习框架。MASkills提出了一种新的智能体优化流水线，整合了技能条件信用分配、层级信用聚合和动量平滑优化，使智能体技能库能够通过改进、归纳、整合和剪枝不断进化。在HotpotQA、LoCoMo和GAIA上的实验证明了MASkills在多种智能体任务中的有效性。我们的代码可在https://github.com/DaRL-GenAI/MASkills获取。

## Abstract
LLM-based multi-agent systems have shown strong performance on complex tasks, yet continual improvement from interaction experience remains challenging. Existing self-reflection methods build experience memories, but memories are mostly hard to invoke, refine, or scale, while agent skills offer a more actionable unit: structured procedural knowledge that specifies when to act, how to act, and which resources or tools to use. We introduce MASkills, a continual learning framework that optimizes multi-agent LLM systems through agent skills. MASkills presents a new agent-optimization pipeline that integrates skill-conditioned credit assignment, hierarchical credit aggregation, and momentum-smoothed optimization, enabling agent skill libraries to evolve through refinement, induction, consolidation, and pruning. Experiments on HotpotQA, LoCoMo, and GAIA demonstrate the effectiveness of MASkills across multiple agentic tasks. Our code is available at https://github.com/DaRL-GenAI/MASkills

## 1. 论文的核心问题与整体含义（研究动机与背景）

基于大语言模型（LLM）的多智能体系统已在复杂任务中展现出强大的性能，但如何使系统从持续交互经验中不断改进，仍然是一个开放且具有挑战性的问题。现有主流方法（如自我反思机制）通过构建“经验记忆”（experience memory）来积累知识，但论文指出这一范式存在根本性缺陷：

- **记忆难以调用**：经验记忆以自然语言片段记录过往轨迹，但缺乏可靠的条件触发机制，难以在恰当情境中被主动唤起。
- **记忆难以精炼**：记录的是“发生了什么”，而非“何种行为策略应当被复用”，无法直接指导策略层面的改进。
- **记忆难以规模化**：随着记忆不断增长，有用的经验会与嘈杂、冗余甚至过时的记录混杂在一起，导致检索效率与信号质量同时下降。

针对上述问题，论文引入了**技能（skill）**这一更具可操作性的优化单元——一种结构化、分层的程序性知识包，包含技能元数据、过程性指令文件和辅助资源（脚本、参考资料等），明确了“何时调用、如何行动、使用什么工具”。在此概念基础上，论文提出 **MASkills** 框架，将多智能体系统的持续改进从“参数空间”或“非结构化记忆空间”中解放出来，转化为对**可复用技能库的持续语言空间优化**。其整体含义在于：通过将交互轨迹中的经验提炼为结构化技能，并将技能更新与团队级协调结果建立因果联系，实现多智能体系统真正意义上的“终身学习”。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 核心思想
MASkills 以合作式多智能体 Dec-POMDP 为形式化框架，将每个智能体的策略通过其技能库进行重参数化，采用一种**语言空间中的类策略梯度框架**（概念性类比，而非真正的微分梯度），直接以技能构件（而非网络参数）为优化变量，在技能空间中执行“类梯度下降”式的持续优化。

### 关键技术细节（四阶段闭环流程）

MASkills 将整个优化过程构建为四个阶段：

**（1）多智能体技能执行（Multi-Agent Skill Execution）**
- 每个智能体的提示中仅注入轻量级技能元数据（如 skill.yaml 中的名称和描述）。
- 智能体自主决定是否调用技能及如何组合技能；技能被选中时，才动态加载对应的 SKILL.md 过程性指令和辅助资源，保持上下文简洁。
- 执行轨迹中显式记录技能调用痕迹，为后续技能级信用分配提供直接观测依据。

**（2）细粒度技能信用分配（Fine-Grained Skill Credit Assignment）**
- 针对团队奖励无法直接归因于具体技能的问题，引入集中式的语言评论器（critic）。
- 对轨迹中每个被调用的技能，评论器通过**反事实比较**（若该技能未被使用会如何）生成细粒度的自然语言信用反馈，判断该技能对团队结果的贡献性质（促进协调、冗余、导致失败、需要泛化或特化等）。
- 评论器还额外输出智能体层面的“残差信用”，用于捕捉无法归因于任何现有技能的效应——这为技能归纳提供了关键信号。

**（3）稳定化的语言梯度下降（Stabilized Language Gradient Descent）**
该模块旨在解决轨迹级语言评论噪声大、异质性高的问题，包含三个子步骤：
- **轨迹级编辑方向提取**：LLM 将文本信用信号转换为结构化的编辑方向（如精炼建议、行为调整、泛化或删除）。
- **层级信用聚合**：沿轨迹、技能、智能体、交互拓扑四个层级递归聚合编辑方向，合并重复模式、消解冲突建议、去除冗余。
- **动量平滑的技能编辑**：引入历史优化周期的编辑方向作为“动量项”，与当前聚合反馈共同驱动技能更新，抑制瞬时或矛盾的评论干扰。

**（4）技能进化算子（Skill Evolution Operators）**
最终通过四种算子实现技能的持续进化：
- **精炼（Refinement）**：对“有用但不够好”的技能进行局部差异化编辑，只修改反馈指向的部分，保留已验证的行为结构。
- **归纳（Induction）**：当现有技能无法解释持续失败时，从困难轨迹中提出全新技能。
- **整合（Consolidation）**：将功能重叠的技能合并为更高级的程序性抽象，抑制技能库碎片化增长。
- **剪枝（Pruning）**：移除长期低效用、冗余或过时的技能。

**（5）验证与回滚机制（Validation and Rollback）**
所有候选编辑须在**保留验证集**（held-out validation set）上通过性能门槛（不低于原技能空间减去容忍误差 δ）方可提交；否则回滚至原技能空间，起到类似“信任域约束”的稳定作用，防止噪声评论或过拟合导致的性能崩塌。

## 6. 论文的主要结论与发现

1. **持续技能优化显著提升多智能体任务表现**：MASkills 在 HotpotQA（F1 76.3）、LoCoMo（单跳 F1 27.61 / BLEU 21.30，多跳 F1 17.22 / BLEU 12.87）与 GAIA（Avg 23.3）上均全面超越现有基线，包括基于提示优化的多智能体方法（如 MultiPersona、ADAS）和专用记忆系统（如 MemGPT、MemGPT 之上的 LoCoMo 基线）。
2. **演化技能优于提示词生成技能**：一次性提示生成的技能相较无技能基线提升有限，而通过 MASkills 迭代演化的技能带来显著增益，说明轨迹驱动的持续性优化比一次性提示工程更能产生高质量的程序性抽象。
3. **技能具有跨任务可迁移性**：从源任务优化的技能不经额外微调即可提升目标任务表现，表明 MASkills 学到的是可复用的程序化行为模式，而非任务特定的提示技巧。
4. **框架对协调拓扑与模型骨干具有鲁棒性**：三种拓扑下均保持了竞争力（去中心化对等结构在检索类任务中最优，集中式在需要全局一致性的长程记忆任务中最优）；在多种 LLM 骨干下性能趋势保持一致。
5. **验证回滚是保证稳定进化的最关键组件**：消融显示，去掉验证回滚后性能坍塌最严重（LoCoMo-MH 从 17.2 降至 6.6，GAIA 从 23.3 降至 13.5），证明信任域风格的更新审批机制对高风险的技能空间编辑至关重要。
